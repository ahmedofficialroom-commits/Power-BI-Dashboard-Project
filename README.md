# Revenue Opportunities Dashboard — Power BI

## Project Overview

**Revenue Opportunities** is an interactive Microsoft Power BI report designed to help explore sales opportunities and understand potential revenue. The report includes an **Opportunity Overview** page and opportunity summary cards, providing a visual starting point for reviewing pipeline information.

The goal of this project is to turn opportunity data into a clear, easy-to-explore report that can support sales monitoring and business decision-making.

## Objectives

- Review sales opportunities in one report.
- Make opportunity information easier to explore through visual summaries.
- Help users spot patterns and areas that may need sales-team attention.
- Present business data in a clear, interactive format.

## Tools & Technologies

- **Microsoft Power BI Desktop** — report creation and visualization
- **Power Query** — data preparation and transformation, where applicable
- **DAX** — measures and calculations, where configured in the report

## Report Contents

- **Opportunity Overview:** the main report page for exploring opportunity information.
- **Opportunity Cards:** summary-card visuals included in the report.

## How to Open the Project

1. Download or clone this repository.
2. Install **Microsoft Power BI Desktop** if it is not already installed.
3. Open `Revenue Opportunities.pbix` in Power BI Desktop.
4. If Power BI asks for a data source or credentials, configure the required connection and refresh the data.
5. Explore the report pages and available interactions.
